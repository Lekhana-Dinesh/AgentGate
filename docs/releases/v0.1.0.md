# v0.1.0 controlled-pilot candidate

## Short Summary

AgentGate `v0.1.0` is a controlled-pilot candidate for teams evaluating runtime governance for AI agent tool use in self-hosted environments. It is positioned as a GitHub-first pilot foundation with operator-facing controls, deterministic policy enforcement, approval workflows, audit evidence, and deployment/rehearsal assets for technical review.

## Highlights

- Runtime governance for agent tool calls before external side effects
- Tenant-aware auth/RBAC with operator roles and scoped control surfaces
- OIDC, minimal SCIM, and browser-session hardening foundations
- Connector foundations for GitHub, Jira, MCP, and mock/demo adapters
- Deterministic policy engine with approval-heavy pilot policy patterns
- Approval workflows, trace visibility, and governed execution paths
- Audit export, tamper-evident audit integrity, and checkpointing foundations
- Durable jobs, worker execution, and scheduler foundations
- Redis-backed rate limiting foundations
- Payload protection and AWS KMS integration foundation
- Operator UI for onboarding, tools, policies, approvals, jobs, audit, retention, settings, and related review surfaces
- Self-hosted deployment, observability, backup/restore, rehearsal, and review assets
- CI, security scanning, release hygiene, and controlled-pilot documentation

## Validation

- Local live rehearsal passed
- Backend test suite passed
- Frontend production build passed
- `npm audit --audit-level=high` passed
- Secret scan passed
- GitHub Actions on `main` were checked manually before tagging

## Known Limitations

- This is a controlled-pilot candidate, not enterprise GA
- This is a self-hosted evaluation foundation, not a managed SaaS offering
- No SOC 2, ISO, or compliance certification claims
- Not positioned as HA/Kubernetes/Terraform maturity
- Not intended for unrestricted MCP connectivity
- Not broad SCIM/SAML identity-governance maturity
- Recommended pilot scope remains GitHub-first, with Jira optional and MCP tightly constrained or disabled unless explicitly reviewed
